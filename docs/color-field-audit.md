## Methodology

For every `sectionType` in the editor's `SECTION_FIELDS`:
1. Resolve all template components from `templates/index.ts` (incl. nested `INDUSTRY_TEMPLATES`).
2. Locate each component's source file by scanning every `.tsx` under `apps/renderer/src/templates/` for `export const/function/class <Name>`.
3. Extract every `var(--…)` reference from those templates.
4. Diff editor fields vs. consumed variables:
   - **DEAD**: editor field shown but no template references its CSS variable.
   - **SHADOWED**: editor writes `--style-X` but templates read `var(--token-Y, var(--style-X, …))` and `--token-Y` is already set at `:root` by `brand-colors.ts`, so the user's value is masked.
   - **MISSING**: template consumes a colour variable but no editor field exposes it.
