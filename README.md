# Flamingo CMS 3.0

Custom CMS + Renderer + Template-System für branchenspezifische Kundenwebsites.

## Structure

- `apps/marketing` — FlamingoMedia Agency Website (Next.js 15)
- `apps/admin` — CMS Admin (coming soon)
- `apps/renderer` — Customer Website Renderer (coming soon)
- `packages/db` — Drizzle ORM Schema (21 tables, Neon Postgres)

## Dev

```bash
pnpm install
pnpm dev:marketing
```
